SYAMRAJ & RITU — GITHUB UPLOAD (WITH LAAL ISHQ)

This package contains the website files and the actual Laal Ishq MP3.

IMPORTANT: Upload the CONTENTS of this ZIP to the ROOT of your GitHub repository (syamraj-ritu-wedding), not the ZIP file itself and not an extra enclosing folder.

At the repository root, you should see:
- index.html
- laal-ishq.mp3
- images/  (folder containing all website photos and venue-qr.png)

Steps:
1. Open https://github.com/syamrajritu/syamraj-ritu-wedding
2. Click Add file > Upload files.
3. Extract this ZIP on your computer. Open the extracted folder.
4. Drag index.html, laal-ishq.mp3, and the images folder into the GitHub upload area. (If the images folder is already in the repository, upload/replace its contents only if prompted.)
5. Scroll down and click Commit changes.
6. Wait for GitHub Pages to deploy, then refresh the website.
7. On the website, tap PLAY OUR SONG. Phones do not allow music to autoplay before a visitor taps.

Keep the existing GitHub Pages setting: Deploy from branch > main > /(root).
